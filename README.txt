IMMORTAL HEROES v0.14.1 - REFERENCE ASSET REBUILD

This package converts the Cleric -> Paladin Skill Tree prototype from procedural programmer-art to an asset-driven renderer using the approved ornate fantasy reference.

Run INSTALL.bat and follow the file prompts. The installer compiles all 8 DLLs in staging before replacing the live set, then installs the cached UI artwork to BepInEx/plugins/ImmortalHeroesAssets.

The renderer has a procedural fallback if the artwork is missing. No combat or progression logic was changed in this build.
