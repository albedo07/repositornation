v0.25.156 Bound Learning (animation handoffs only; combo counters / timing / configs untouched)
- Every local Attack.Start is one activation (AttackSerial + the Attack object). A pending state learn is bound to its own activation: dropped when any other attack starts, and when its Attack is no longer the player's current attack.
- IsSwingState with an SBDW / 2HDW override controller: the playing clip must be the bundle clip for the requested slot (swing N -> Attack N+1, via the replaced clip's name); a clip replaced for another slot is rejected. Clips the override does not replace (and plain controllers) need the state name of the requested trigger, or an attack event on a state that was just entered (not a swing already running). An attack event alone no longer qualifies.
