2. Size caches above the real working set and never clear-all on overflow in a hot loop (Variants 96 thrash = constant GC + first-cast hitches).
3. "First cast" fixes need data that exists before the first cast (CsTiming guessed 0.85 s; learn from the animator at load). Grep for "first cast guess"/defaults.
4. Verify a perf fix against the NEXT report before claiming it: v239 HUD caches missed the real allocator (hotbar). Trace the full call graph (an agent) before editing.
5. Prove a background warm-up finished: log completion and log on failure (v238 JIT warm died silently).
6. Edit scripts are atomic: compute all files, assert all anchors, then save (v240 first attempt half-wrote Runtime). Anchor duplicate snippets to their method (RA helper).
7. Every pass: tools/realbuild.sh (all ten modules vs the user's real DLLs in scratchpad realrefs + jot/) before delivery; cached compile = static only, never claimed as in-game.
