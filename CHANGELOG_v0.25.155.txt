v0.25.155 Handoff Guards (animation handoffs only; no configs / defaults / gameplay changed)
- TuneVanillaRoutine (Start / End % trim of directly fired vanilla swings) now owns the animator only while its activation is the newest: new DragonCombat.AnimActivation is bumped by every new skill animation (PlayClip, FireVanilla) and every accepted normal attack (RetireSkillAnimations). The routine also stops if the animator's controller changed. Checked before every wait result and before every CrossFade (start % jump, end % cut-back).
- IsSwingState validates the REQUESTED swing: state name == the consumed trigger (or its external Warfare/Wizardry mapping), or - for a renamed SBDW/2HDW override state - a clip with an attack event; locomotion/skill/looping clips rejected; a state already owned by another swing of the controller is never cached as a second one; 2HDW paired-override must still match what it was at learn time. The "unknown clip, accept" path is gone (unlearned swings use the existing HasState fallback).
