IMMORTAL HEROES — NAMED ANIMATION BLUEPRINT
Review baseline: Immortal_Heroes_v0.25.14_Smooth_Motions.zip
Date: 5 October 2026
Status: proposed art/motion direction and implementation handoff; NOT an implemented animation mod.

PURPOSE AND SCOPE
Create a reusable movement language that looks intentional for each skill. Reuse whole performances when actions truly match, equipment-specific variants when hand use differs, and individual phases when only part of an action matches. Do not force unrelated mechanics into one generic cast.

Coverage: 68 unique active skills, Ultimates and Graces: four base classes plus eight advancements. Inherited base skills are documented once and reused in both branches. Also includes the relevant passive/weapon/proc motions below. Kali and its advancements do not have implemented kits in the reviewed source; no invented skill mapping is included for them.

Naming: Archmage uses the legacy internal class ID Wizard. Horizon Walker uses Spellcaster. Angel Comet remains fallen_angel internally. Heaven’s Crucible remains grand_sigil. Deadeye Draw is the proposed animation name; it is separate from Bowmaster’s Deadeye mastery. The ranged sketch abbreviates it to DEADEYE.

Package order: read this blueprint, look at the six storyboard sheets, then use animation_blueprint.json and skill_animation_map.csv for structured mapping. Source animation calls are supplied separately with original source line numbers. The pictures express silhouette and action direction; the written event/hand/collision contracts take precedence over incidental drawn equipment, effect color or geometry. These are concept sketches, not rigged clips or exact hitbox diagrams.

REUSE MODEL
Twenty families are proposed. This does NOT mean twenty finished production clips: left/right equipment profiles, rising versus falling strokes, hold loops, exits, ground/air variants and contact limbs still require authoring. The current source contains 89 named procedural clip presets; that is not a count of 89 unique imported/rigged animations. The benefit is shared choreography and event contracts, not a promised percentage reduction in file size or work.

Exact or near-exact shared core:
- Olympic Hero: Electric Smite + Bonecrusher. Same complete roll/landing, different weight/VFX.
- Sky Command relic profile: Goddess Relic + Lightning Relic + Holy Relic. Same remote summon motion.
- Wavecaller: radial healing, buffs and barriers. Small hand inserts personalize a Grace without changing the core.
- Rebound Shot: Tumble Shot + Gale Volley. Same backflip path/apex release; projectile fan differs.

Shared family with authored variants:
- Earthbreaker: descending Seismic/Greatblade and rising Impact Wave; do not reverse-play one clip.
- Power Pitch: hammer overarm throw versus bomb bat swing; torso mechanics shared, arm paths differ.
- Vanguard: shield drive versus sword thrust; shield leads with off hand, sword with main hand.
- Deadeye Draw / Sky Archer: bow and crossbow require different grip and firing profiles.

Partial composition:
- Skyfall: Rebound launch module + Sky Archer hover, then airborne/grounded recovery.
- Halfmoon: Arc Cutter sequence + held stance + optional Cyclone finish.
- Angel Comet and Swallow Dive: common streamline/exit, different actual movement paths.

NON-NEGOTIABLE GAMEPLAY CONTRACT
1. This pass changes presentation. Do not alter damage, ticks, charge counts, cooldowns, resource costs, range, projectile collision, movement distance/speed, target selection, boss rules, i-frames, armor or combo logic for animation convenience.
2. Use executable behavior and current config as authority. Some old menu prose is stale. Do not restore earlier chat proposals when the ZIP has moved on. In particular: current Halfmoon has an optional held finisher; current Greatblade is not a charge attack; current Ascended Rift Echo uses multiple rifts; current Afterimage behavior is supported weapon mirroring, not arbitrary all-skill replication.
3. Existing skill locks remain unchanged. An immediate effect can still have a short existing post-cast lock. “Instant/release-first” means no added latency, not a promise that all inputs are unlocked.
4. Caster release, projectile collision, target detonation, landing and pulse ticks are different events. Bind each visual to the correct existing callback. One authoritative gameplay path applies damage; the animation never also applies a duplicate hit.
5. A barrage, aura, summoned relic, afterimage or delayed shock can keep working after the player recovers. Do not force the player to pantomime every world tick.
6. Do not add Warrior/Sorcerer mark-and-detonation mechanics. Cleric’s existing interactions remain untouched. Bosses do not gain stun/freeze/immobilizing reactions from a visual flourish; do not change status implementation during this art pass.
7. Base-class motions remain shared across both advancements. Equipment and legal movement profiles can differ; the underlying Cleric/Warrior/Sorcerer/Ranger identity does not become two unrelated sets.

TIMING AND EVENT VOCABULARY
W = the ACTUAL scaled wind-up selected by the executing skill branch, not a constant copied from a tooltip.
- Wind-up cast: prepare during W, reach release/contact at the existing callback, then cosmetic recovery.
- W = 0: sample the release key on accepted input and play follow-through afterward. Never introduce 0.1–0.3s latency merely to show anticipation.
- Charge: enter, hold quietly, release on the existing input condition. Existing charge/wind-up overlap stays intact. A max-charge visual loop can continue as long as the mechanic permits.
- Channel: enter, loop for actual active duration, exit on the real stop. Tick rate is unrelated to animation frame rate.
- Dash/jump: movement code owns translation; pose follows movement phases. Landing requires contact, not animation completion.
- Proposed cosmetic follow-through ranges in the family descriptions are art targets, not new locks. They can blend out immediately when current input rules permit.

Suggested event names are design labels, not existing API names. Map them to actual callbacks before implementing:
CAST_RELEASE / SHOT_RELEASE / STROKE_RELEASE: commit the authorized cast or projectile.
PROJECTILE_CONTACT / WORLD_IMPACT: object hits its target or ground.
GROUND_CONTACT: character reaches valid ground.
BUFF_APPLY / HEAL_APPLY: existing authoritative support application.
CHARGE_START / BEAM_START / BEAM_END / CHANNEL_COMPLETE: sustained-state transitions.
COMMAND_ACCEPTED / VOLLEY_ARMED / TARGET_DETONATION: separate remote command stages.
TELEPORT_COMMIT: one instantaneous root move, preserving active pose.
RETURN_CONTACT: successful returning hammer catch, not a timer assumption.

OLYMPIC HERO — EXTRA PRECISE DIRECTION FOR CLAUDE
Facing convention: forward is the player’s attack direction. Main hand is normally right; mirror only if the actual equipment system requires it. Maintain consistent handedness across the whole motion.
The spin is an axial/barrel roll around the character’s head-to-feet axis while the torso is nearly horizontal. It is NOT a backflip, cartwheel or upright pirouette. Main elbow stays chambered; the shield remains close. Make one complete roll, then visibly unwind toward the landing before ground contact.
Final pose: main fist on ground, opposite foot planted in front, main-side knee folded behind and near the ground, torso over the fist/forward leg, head looking toward the action. Elbow slightly bent; never hyperextend through terrain. The fist must not touch during the airborne unwind panel.
Preserve the current movement routine’s ascent/hang/descent. Roll over ascent and apex, prepare contact during descent. A cliff can lengthen descent, so hold/adjust the poised falling state rather than freezing the animation at an already-grounded pose. Low-ceiling safety uses a compressed roll or no-roll variant while preserving accepted cast/impact timing.
Electric Smite: sixteen ground-running trails at contact; Ascended storm can persist afterward. Bonecrusher: physical impact/dust/fractures, with delayed Ascended shock independent of recovery. Neither gains a second landing or a new hit because the body rolled.
Literal fist contact with a weapon equipped requires render-only weapon stow/visibility restoration or an approved grip-safe variant. Do not unequip items, change stats, fabricate a new weapon or leave the main weapon hidden after cancellation. A shield stays equipped in the off hand.

EQUIPMENT, LAYERS AND INTERRUPTS
- Keep weapon attachment ownership stable. One-hand + shield, two-hand, dual physical weapons, staff/wand, dual Gun Staves, bow and crossbow need explicit hand profiles.
- Bow: left hand holds bow, right draws/releases string. Crossbow: brace/trigger; no invisible string draw. Staff grip must not switch hands between panels unless deliberately animated.
- If both hands are occupied by firing, a mobile magical command can reduce to wrist/head/VFX; it must not stop the weapon merely to display a finger point.
- Grounded feet require real leg motion/contact; torso bending alone is not a crouch. Airborne-legal skills use an airborne overlay rather than a fake ground plant.
- Gameplay root/rigidbody owns displacement and collision. Visual-root lean/rotation is presentation only. Do not move the collider twice or derive damage position from a rotated visual hand.
- Priority: valid gameplay movement/cast > its required weapon/aim pose > cosmetic recovery > automatic buff/survival accent. Teleport is a transition that preserves the active pose, not a competing full-body cast.
- A new valid skill can interrupt cosmetic recovery wherever input rules permit. Old clip cleanup must not reset bones or visibility owned by the new action.
- On cancellation, interruption, death, equipment change or scene unload: release only owned visual offsets/tokens, restore temporary render-only weapon visibility, end hold loops, and stop obsolete VFX bindings. Do not cancel world effects that current gameplay intentionally leaves active.
- Full turns should retain accumulated rotation during the spin, then blend equivalent final orientation without a backward full-circle unwind.

PASSIVES, NORMAL ATTACKS AND AUXILIARY ACTIONS
Warrior’s Blessing: static bonuses/Hyper Armor do not require a cast pose. Keep normal melee/parry reactions; no unsolicited roar per hit.
The Way of the Sword: preserve normal sword animations at the current attack speed. Block/dodge cancellation still stops the rest of a Sword Master skill. No forced animation on passive bonuses.
Warfreak / Unchained Fury: keep current dual-wield/two-hand weapon attacks. Fury can use War Cry’s small additive chest accent; if a skill owns the body, use VFX only. Never restart an attack when Fury triggers.
Cleric’s Blessing: passive shield/staff permissions and stats require no cast. Equipment profile correctness is the animation work.
Heaven’s Will: passive equipment/damage modifications require no cast. Do not create extra attacks for converted damage components.
Bless Thy Sinners: Phoenix Rise is a small automatic recovery accent, not a knockdown or resurrection scene. Apply survival immediately. An ally save is an effect on that recipient, not a forced full caster animation. Current buckler parry shock uses a brief Wavecaller shield-opening accent if it does not overwrite the valid parry; otherwise VFX only. Empowering the next skill does not change its action choreography.
Warlock: stat/equipment rules need no animation; keep current staff/wand attacks and restrictions.
Archmage mastery: charged normal staff shots use Siege Caster’s aim/hold/release. Preserve actual normal-attack charge rules and projectile type. Overcharge uses War Cry’s quiet additive arcane variant, or VFX only while casting. Do not confuse the mastery with the display class rename.
Yin and Yang: maintain mobile rapid staff/wand fire and paired Gun Staff grips. Simultaneous weapons must not both try to own the same arm. Summon/portal gestures are low-priority overlays. Copies mirror supported weapon animations, not recursively summon more copies or recast player skills.
Wildborn: keep the current quick-shot Left Click timing/chain and Right Click charge. Deadeye Draw supplies release/hold styling without extra startup. Preserve one recoil source; the changelog specifically removed stacked recoil.
Windstep: double jump can reuse Rebound’s launch/tuck module without an apex shot. Do not award extra arrows, distance, i-frames or another jump. Grounded Ranger skills require legal airborne pose variants when Acrobat casts them aloft.
Deadeye mastery: Focus buildup needs an aim/VFX accent at most; do not restart a full draw animation each stack. Retain current crossbow reload behavior. Deadeye Draw is just this pack’s name for the reusable firing family.

SOURCE AUDIT — FINDINGS TO ADDRESS WHEN CODING
These are source-review findings, not claims of in-game reproduction. The supplied build was not launched or playtested for this deliverable.

A. Legs are missing from the current procedural pose vocabulary.
DragonsAltar.CombatRuntime.cs, DragonSkillClipDriver, approximately lines 1633–1700: ten controlled bones cover pelvis/spine/chest/head and arms/hands, not knees/feet. Olympic Hero, Rebound, kneels and real stomps need leg support or authored full-body clips/contact handling. Do not fake them by rotating only the torso/root.

B. The driver clamps all wind-ups to at least 0.1s.
CombatRuntime.cs:1669. Immediate effects such as Zap/Holy Wave/Flame Burst and several Ranger shots can run before the pose reaches release. See Skills.cs:783,847,885 and Ranger.cs:578,819, plus the corresponding effect code. Fix phase initialization/event binding; do not solve presentation lag by nerfing responsiveness. Tumble’s very short visual wind-up also needs alignment with the existing apex callback.

C. The generic hold has a fixed 12s visual limit.
CombatRuntime.cs:1673 and the phase logic around1714. Meteor and Ballista can remain held after reaching maximum charge in their current routines. The visual hold can therefore expire while gameplay still waits. Use actual charge/channel state for visuals, with an explicit cleanup path; do not auto-fire the skill at 12s to match a clip.

D. Landing animation starts after movement returns, while damage is applied immediately.
Advanced.cs:2865 onward (BonecrusherRoutineV) and4640 onward (ElectricSmiteRoutine): land_crash/cleric_land begins with a lead-in when the impact callback already runs. Pre-position the contact pose before landing and commit contact at the same authoritative event. The existing jump helper around5217 uses a30s landing safety timeout around5282. Its callers should distinguish genuine contact from timeout/cancel to avoid a possible false airborne impact. This is a correctness concern to verify during implementation, not an observed playtest result or permission to change combat balance.

E. Root/pose jitter was already repaired.
CombatRuntime’s stored base/written poses and transition handling plus CHANGELOG_v0.25.14.txt: retain anti-accumulation behavior. Do not add this frame’s offset to last frame’s already-modified bone, or restore old oscillating wind-ups removed from Halfmoon, Fury/Overcharge, Frost Nova and Tailwind.

F. Local/remote presentation needs an explicit decision.
CombatRuntime.cs:1848 onward PlayClip checks the local player. This entry point alone does not prove animation replication to remote players. Audit existing networking before promising other players see the new motions. If replication is needed, transmit authorized action/state events and derive pose; do not replicate gameplay damage through the art layer.

G. Trace live call sites before replacing legacy code.
Old BodyMotionRoutine/legacy pose sections still exist. Match the executing cast path and named clip calls in SOURCE_ANIMATION_CALLS.json. Editing a similarly named unused routine can leave the actual skill unchanged. A clip name can also be reused by unrelated gestures, so map skill state plus clip, not the string alone.

H. Automatic procs can replace an active pose if routed through the same full-body player.
GuardianAngel.cs:170 starts cleric_rise; Sorcerer.cs around3137 starts wiz_overcharge. Design automatic reactions as low-priority additive/VFX-only when a movement or cast owns the body. Preserve the actual proc effect regardless of animation priority.

IMPLEMENTATION ORDER FOR CLAUDE
1. Map current action callbacks, locks, equipment profiles and source presets. Introduce explicit release/contact/hold-state bindings without changing effects.
2. Implement Sky Command relic sharing, Wavecaller radial sharing, Pulse Drive and mobile Rift Conductor. These provide the widest low-risk reuse.
3. Add leg/contact capability and render-only equipment restoration before Olympic Hero/Rebound/Ground Seal full-body poses. Prototype Electric Smite and Bonecrusher together on flat ground, then slopes/cliffs/low ceilings.
4. Implement martial sequences and continuous spins with current cancellation and accumulated-turn handling. Validate two-hand/shield/dual-wield profiles.
5. Implement bow/crossbow profiles, charge/hover/channel states and teleport preservation. Fix instant-release alignment instead of delaying attacks.
6. Review normal and Ascended variants side by side; certify that only intended visuals changed. Keep existing gameplay formulas/configuration untouched.

ANIM_01 — Olympic Hero
------------------------------------------------------------

Purpose: A near-horizontal aerial barrel roll into a main-hand superhero landing. The same performance reads holy or brutal through VFX and weight, not different body choreography.

Key poses:
  1. Load: compress knees, coil hips and shoulders, main elbow chambered; shield stays close.
  2. Launch: extend legs through the existing jump, then incline the torso almost parallel to ground.
  3. Roll: rotate once around the head-to-feet axis while horizontal; knees loosely tucked, head locates the landing area.
  4. Unwind: complete the turn, unfold legs and bring main fist down; the hand remains above ground.
  5. Impact: main fist contacts, opposite foot plants forward, same-side knee folds behind; elbow stays slightly bent.
  6. Recover: hold weight briefly, push through forward foot, lift fist and blend to current combat/locomotion pose.

Timing: Event-driven. Preserve current takeoff delay and physical ascent/hang/descent. Distribute the visual roll over ascent and apex; complete it before final contact preparation. Descent may be arbitrarily longer on a cliff. Suggested cosmetic contact settle 0.08–0.12s; recovery 0.20–0.35s, cancelable when existing input rules permit. These are proposed visual timings, not new locks.

Body layer / movement: Full body plus visual-root orientation; gameplay rigidbody retains all translation/collision authority.

Authored variants: Holy: Electric Smite, same roll and fist impact. Brutal: Bonecrusher, slightly deeper compression and heavier settle, same timing contract. No second jump for its Ascended aftershock.

Event synchronization: GROUND_CONTACT is authoritative. Pre-position the landing pose so the contact key coincides with the existing damage callback. Play 16 ground trails for Smite, physical dust/shock for Bonecrusher. Delayed aftershocks use world events after the player has recovered.

Do not break: Requires explicit knees/feet and contact support, absent from the current ten-bone clip vocabulary. Never fire on an aerial timer. With equipped weapons, use a reversible render-only stow/visibility profile for the main weapon if literal fist contact is required; never unequip or alter stats. Shield stays in the off hand. If stowing is unavailable, show a grip-compatible hand-led impact and flag it for review rather than passing a blade through the ground. Low ceilings use a compressed/no-roll safety variant without changing hit timing.


ANIM_02 — Sky Command
------------------------------------------------------------

Purpose: One shared call-and-lower motion for distant sky summons and overhead bombardment.

Key poses:
  1. Gather: main hand or casting implement crosses the sternum; gaze confirms the remote target.
  2. Call: lift the main arm overhead, off arm balances or keeps a shield close.
  3. Hold: keep the raised silhouette quiet, with slight breathing only; track legal aim.
  4. Release: pull the arm down and point toward the target.
  5. Recover: return to guard while the summoned object continues independently.

Timing: Fit gather/call into the existing scaled wind-up: roughly 0–35% gather, 35–80% lift, 80–100% direct/release. A charged version inserts a hold before release; charge and wind-up keep their current overlap. Do not add travel time to the caster lock. Instant applications use a short release-first upper-body gesture.

Body layer / movement: Upper body by default; planted leg variant only while existing movement restrictions apply.

Authored variants: One-hand + shield; two-hand staff; unarmed palm; charged two-arm lift; large ultimate reach. All use the same event order. Relics share the same actual cast style, not just similar titles.

Event synchronization: CAST_RELEASE starts or commits the summon. WORLD_IMPACT happens later at the target and owns collision/damage/pulse start. Barrage ticks do not require repeated caster motions.

Do not break: Goddess, Lightning and Holy Relics descend remotely in this build: the caster must not look as if manually planting them at their feet. Never aim a vertical lightning strike from the caster hand. Preserve indoor-safe spawn height and drop duration. Late hold release is input driven, not a fixed animation timer.


ANIM_03 — Wavecaller
------------------------------------------------------------

Purpose: A short gather-and-open gesture for radial healing, buffs, barriers and self-centered bursts.

Key poses:
  1. Gather: main hand near sternum, shoulders draw inward slightly.
  2. Open: lift chest and open the main forearm outward; free off hand follows or shield stays guarded.
  3. Pulse: a clear outward opening signals the radial wave centered on the correct source.
  4. Recover: hands settle without making the character kneel or stop walking.

Timing: For instant skills, the effect occurs at accepted input; start the visual at its open/pulse key and use 0.15–0.30s nonblocking follow-through. Wind-up skills can use the full gather phase. Suggested recovery 0.15–0.25s, interruptible. Effect duration does not become animation duration.

Body layer / movement: Upper-body additive; locomotion and aiming continue wherever current mechanics allow.

Authored variants: Blessing: soft raised palm. Barrier: protective forearms open. Frost: stronger compression and sharp outward snap. Command salute: brief brow/weapon salute feeds the same opening for Knight’s Guidance and Hawk’s Vigil. These are hand-profile variants, not changes to pulse shape.

Event synchronization: BUFF_APPLY / HEAL_APPLY / NOVA_RELEASE occur once at their existing callback. An allied/relic source remains there even though the caster performs the gesture. Persistent aura ticks and expiration bursts are independent.

Do not break: Self waves are 360-degree radial rings, not forward beams. Do not force full-body recovery on instant heals. Damage or healing events are never duplicated because two arms open. Shield/staff/bow remains attached to its original hand.


ANIM_04 — War Cry
------------------------------------------------------------

Purpose: A compact chest-led rally with a larger deliberate version and a small automatic reaction.

Key poses:
  1. Gather: elbows bend inward and torso compresses slightly.
  2. Open: shoulders spread and chest rises over balanced hips.
  3. Roar: head lifts modestly and fists/weapon widen.
  4. Recover: return to the current stance without overshooting or trembling.

Timing: Battlecry uses a brief visible release at actual buff application, then 0.25–0.45s cosmetic settle. Automatic Fury/Overcharge uses at most a 0.10–0.20s additive accent, or VFX only during a conflicting action.

Body layer / movement: Upper-body additive by default; full stance only when idle and permitted.

Authored variants: Mercenary: grounded fist clench and roar. Archmage: arms open and energy breath. Automatic proc: shoulder/chest accent only.

Event synchronization: PROC_GRANTED and BUFF_APPLY must not wait for the visible pose. An automatic proc cannot replace an active skill clip or alter its scheduled impact.

Do not break: Do not reintroduce the oscillation removed in v0.25.14. No camera shake baked into bones. No forced attack interruption, stun or root movement for an automatic trait.


ANIM_05 — Arc Cutter
------------------------------------------------------------

Purpose: A reusable coil–cut–follow sequence whose plane and sequence count match the skill.

Key poses:
  1. Coil: weight settles, weapon chambers to the chosen side, head stays on aim.
  2. Cut: hips lead and shoulders follow as the weapon crosses the intended plane.
  3. Follow: blade finishes past the target line, elbows remain plausible.
  4. Reset: return through a short guard or chain directly into the next chamber.

Timing: The cut crosses its release plane at each existing attack callback. For repeated waves, reuse alternating cuts at the existing cadence, blending from current pose instead of returning to idle. Charged variants hold in coil and release only when the current skill allows.

Body layer / movement: Upper body with a limited stance layer; translation remains owned by gameplay.

Authored variants: Horizontal: Heavy Slash/Moonlight/Halfmoon. Opposing diagonals: Grand Cross’s two cuts. Fan: Crescent Cleave emits several remote cleaves from one broad sweep. Heavy finishing cut: increased amplitude, not a free extra hit.

Event synchronization: CUT_RELEASE emits the intended projectile/wave or activates the melee snapshot. One fan can emit many projectiles. Afterimages are effect events, not necessarily additional physical swings.

Do not break: The current warrior_heavy pose is diagonal while its lore calls it horizontal: use horizontal here. Moonlight’s horizontal wave should not be represented as an unrelated vertical slam merely because the existing finisher clip does that. Do not count every VFX trail as a new attack.


ANIM_06 — Earthbreaker
------------------------------------------------------------

Purpose: A shared grounded power-stroke family with separately authored descending and rising paths.

Key poses:
  1. Load: bend knees and set weapon close to the body.
  2. Prepare: descending version raises overhead; rising version draws low behind the hip.
  3. Drive: transfer weight as weapon crosses down or up through the target plane.
  4. Release: ground fissure/astral blade/wave starts along the authoritative aim.
  5. Recover: unload the pose and return to guard or next slam.

Timing: Use the existing wind-up W and release at its end. Repeated slams get one drive per real slam event. Suggested cosmetic settle 0.15–0.30s; no additional charge stage.

Body layer / movement: Full upper body; stance layer only when movement is already committed.

Authored variants: Downstroke: Seismic Guillotine / Astral Greatblade. Rising stroke: Impact Wave. Rising is a separately authored motion variant, NOT reverse playback of the downstroke: grips and balance must make sense.

Event synchronization: STROKE_RELEASE starts the traveling ground effect; endpoint impact belongs to the effect. Greatblade aligns to crosshair aim, not an outdated torso facing.

Do not break: Do not turn Seismic Guillotine into a falling guillotine prop. Do not make Impact Wave a downward stomp. A giant spectral blade can exaggerate weapon size without stretching the player skeleton.


ANIM_07 — Ground Seal
------------------------------------------------------------

Purpose: A reusable low weight shift for a grounded command, stomp, or trap placement.

Key poses:
  1. Load: transfer weight to support leg, keep eyes on valid target.
  2. Lower: bend both knees with a modest torso hinge.
  3. Contact: foot stamps, staff butt presses, or free hand reaches down according to profile.
  4. Recover: rise through legs; do not pop the whole model upward.

Timing: Contact occurs at the real stomp/placement/cast callback. If an effect is immediate, begin at a shortened contact pose rather than postponing the effect. Follow-through 0.15–0.30s is cosmetic. Remote persistence does not require repeated stamping.

Body layer / movement: Leg-aware full body for planted casts; mobile upper-body command variant for Horizon Walker’s instant Stonefang.

Authored variants: Stomp = foot contact. Stonefang = staff/palm command, effect at aimed ground. Snare = small careful placement, not an impact explosion. They share lowering/recovery, but have distinct contact limbs.

Event synchronization: LOCAL_CONTACT authorizes the visual stomp/placement cue only. REMOTE_ERUPTION stays at the aimed location. Subsequent shocks/ticks run independently from the original center.

Do not break: No chest-through-knees bend to fake a crouch. Snare may be targeted remotely in code: show a placing/dispatching gesture without moving the player to the target. Acrobat airborne casting uses a wrist command instead of forcing ground contact.


ANIM_08 — Flash Draw
------------------------------------------------------------

Purpose: A short sword command that causes several cuts at a remote point.

Key poses:
  1. Ready: main hand draws toward the opposite hip, blade safely angled.
  2. Draw: a fast compact outward cut, head tracking the remote aim.
  3. Release: remote slash sphere appears; torso does not teleport there.
  4. Reset: controlled return to hip guard or next cast.
