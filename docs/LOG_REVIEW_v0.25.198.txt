ACTIONABLE CANDIDATES FOR PASS THREE
1. EXP prefab scan: 392 caught null-reference warnings. Current Update scans uninitialized creature prefabs and Discover calls creature.GetMaxHealth(). Prefabs do not necessarily have the runtime network/health state that method expects. Investigate reading the serialized prefab health safely for discovery while preserving all existing configured rewards, scaling and earned EXP. Do not rebalance rewards as part of the fix.
2. Harmony inherited-method warnings: CombatRuntime targets Character.Damage / Humanoid.BlockAttack through inherited reflections; Advanced has the Character.Damage warning; Sorcerer has Character.TryUseEitr. Resolve the actual declaring implementations and avoid registering the same implementation more than once. Verify damage/buff hooks still run exactly as intended; do not suppress warning output without fixing the target selection.
3. Missing UI frame assets: eight warnings; cyan frames are absent for several Cleric/Paladin skills, and the Electric Smite colored frames are absent while a red frame exists. Existing procedural fallbacks prevent hard failure. Check intended alias/fallback selection and caching; preserve the established UI appearance. Not evidence that game skills failed.
4. Performance monitor: Advanced OnGUI averages 0.497ms overall and allocates approximately 552KB/s in the measured AA section, the largest reported AA allocation source. Review cached labels/style/layout only where measured and behavior can remain identical. The idle/overall comparison is not an isolated per-skill benchmark. The report lists total 4.92MB/s for the game/all mods, not AA alone.

PERFORMANCE INTERPRETATION
Recorded 2,184 seconds. Idle frame 12.93ms, AA measured code 0.50ms/frame. Overall frame 10.58ms; worst 261.3ms. Render/GUI/physics/GPU-wait aggregate averages 10.84ms idle / 8.49ms overall. Recent 33.3ms stalls show about 0.1-0.2ms of measured AA script time and roughly 31ms in that aggregate. This cannot distinguish GPU load, unmeasured work, physics, other mods or frame limiting, and does not establish a specific AA-script cause. No recorded VFX spawn maximum exceeds 8ms. Preserve visuals unless a verified identical-result optimization is available; do not remove particles or mechanics to invent an FPS win.
