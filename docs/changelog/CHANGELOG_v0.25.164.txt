v0.25.164 Clean Slate (baseline v0.25.163)
1. HUD (Ranger + Sorcerer, every AC recolour): painted HP / STAMINA / EITR / EXP label column fully removed. CAUSE: the column's colour was replaced but its ALPHA still came from the painting, so the old labels and icon chips ghosted through. Fixed in tools/build_hud_frames.py. Ranger: label column reaches past STAMINA, empty troughs opaque (the world showed inside the HP / Eitr bars), food slots repainted empty (leaf garnish + count diamonds were left behind). Warrior / Cleric frames, layouts and bars byte-identical.
2. Staves: CAUSE of doubled shots / changed intervals / gaps = a leftover of the removed dual-Gun-Staff mode rewrote every Gun Staff's shared attack data while a Horizon Walker held it (draw / charge / warm-up zeroed, cooldown / 1.5, accuracy + movement factors forced). Removed; native data restored. Horizon Walker: full movement speed while firing any staff / wand / Gun Staff (Humanoid.GetAttackSpeedFactorMovement postfix, no item data touched) and the legs keep a walk / run cycle while moving + firing (HwLegCycle, after the animator); standing still = native animation. Yin and Yang's attack speed is unchanged (Mastery).
3. NACC first-use "sit": CAUSE (code + Valheim's Player.SetupAwake / UpdateAwake): assigning an animator controller resets every parameter to the controller default and restarts the entry state; Valheim sets "wakeup" (sit-up pose), statei/statef and attach / emote bools only on events, so the first controller swap of a session (2HDW SBDW override on the first primary) could leave the player sitting until the next trigger. Every controller swap now goes through DragonCombat.SwapController (non-trigger parameters + each layer's state carried over). Combo, timing, triggers unchanged.
4. Skill tree: no Class / Advancement selection or AC preview any more (branch plaques + ADVANCE plaque removed; the tree's advance action only points to the Altar). Before Advancement the Advancement side is sealed with the requirement list. Learning, upgrading, ascending and current-class tooltips unchanged.
5. Tooltips (tree + Altar): one plain description sentence, then only Tier (n/max · +x% Damage), Damage (healing as "Heal"), DoT, Atk Debuff, Atk Range, Atk Radius, Stamina / Eitr / HP Cost, Cooldown, Ascension Description (only while the skill can still be Ascended). Values come from the existing live stat builders. TIER: damage now reaches exactly +80% at every skill's max Tier in GAMEPLAY (Class 7 = +11.43% per Tier, Advancement 5 = +16%, Ultimate 3 = +26.67%); healing keeps +10% per Tier. Circle Swing, Seismic Guillotine and Whirlwind now apply their Tier in gameplay (they never did).
6. Daggers: paired daggers (2HDW knives) are out of AA's NACC (vanilla chain); Kali's NACC no longer lists Knives. 2HDW and SBDW daggers stay Mercenary-only (equip rules unchanged).
