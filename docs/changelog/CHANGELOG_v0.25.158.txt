v0.25.158 SBDW Only (2HDW animation ownership; heavy attacks, damage, Mercenary restrictions, SBDW 1-2-1-2-3 timing untouched)
- A 2HDW primary swing is never played with the native (Therzie / Warfare) animation any more. On an invalid controller the override is REPAIRED: rebuilt from the correct base controller (candidates: the current controller's chain, the controller we replaced, the last base that validated); each candidate must replace the carrier's three clips (axe_swing / Axe combo 2 / Axe combo 3 - not just any Attack1-3 names) and the assigned controller must declare the carrier triggers (swing_axe / axe_swing x3, animator parameters only). Repairs reuse the built override (no re-instancing).
- If repair fails the attack is REJECTED: Humanoid.StartAttack (primary, paired weapon, not mid-swing) returns false before Attack.Start - no stamina, no trigger, no combo advance. Attack.Start prefix is now a skip-prefix with the same rule as a second guard; if the controller is stolen after Start, the swing is cancelled and its native trigger suppressed. Cause is logged ("WARNING [2HDW] ... attack rejected - <reason>") and shown once.
- Heavy (secondary) attacks and non-paired weapons never enter this path.
