TEST THIS BUILD - v0.23.1 Wizard
================================
First start resets every setting to default (Dev Mode OFF). F8 -> DEV MODE to test.
Ascended versions: F8 > Progression > ASCENDED switches.

1. Meteor Fall: tap = normal; hold the key = 1/2/3 stacks (message), bigger meteor + ring.
2. Astral Greatblade: aim with the crosshair (not where you face); hold = charge to 2x.
3. Elemental Cataclysm: tap = quick cast; hold up to 6s = up to 3x.
4. Railcannon fires where the crosshair points.
5. Frost Nova: Frost, Stun Small, Big staggered + slowed.
6. Overcharge: spend 300 Eitr -> "OVERCHARGE" for 12s (faster casts, more damage/regen).
7. Clockwork (M4+R): cast a skill during it -> its cooldown is halved; tooltip shows stats.
8. Ascended: Glacial core Freeze; Meteor small meteors; Gravity pulls Big + end blast;
   Railcannon steerable beam (hold the key); Greatblade 3 slams; Frost Aura 6s + freeze
   blast; Cataclysm second bombardment.
