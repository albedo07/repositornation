v0.25.184 Performance Monitor - how to use
1. Load in, press F7 (overlay top right appears).
2. Stand idle ~20 s (baseline), then cast each skill you suspect a few times with ~5 s between casts
   (Furious Winds, Eclipse Asc, Seismic, Blade Storm, Ultimates...). Normal fighting also works.
3. Optional A/B: Alt+F7 (effect lights off) and repeat the heavy skills.
4. Press F7 again -> report written to BepInEx/plugins/Aethelborn_Performance.txt. Send me that file
   (and LogOutput.log if something looks off).
Check: with the monitor OFF, nothing behaves differently from v0.25.183.
